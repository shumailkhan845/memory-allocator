# Memory Allocator in C

A custom dynamic memory allocator built in C to understand how memory allocation works internally.

## Goals

* Understand virtual memory and operating system memory management.
* Implement custom `malloc`, `free`, `calloc`, and `realloc` equivalents.
* Manage memory blocks using metadata and free lists.
* Implement block splitting and coalescing.
* Study alignment and memory fragmentation.
* Test correctness and benchmark allocation performance.

## Learning Approach

This project focuses on understanding system design, memory layout, pointer arithmetic, and how allocator components work together.

Implementation is developed incrementally, with explanations, tests, and Git commits for each session.
